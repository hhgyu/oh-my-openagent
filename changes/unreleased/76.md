## 2026-11-16 - Whole-tree build freshness gate (#76)

The build job installs with `--ignore-scripts`, then runs `bun run build`, so the build is the first writer of every generated file. Before, only the two JSON Schemas were diffed afterwards; the Senpi bundles were checked on the senpi-compatibility ubuntu leg alone, and other generated outputs (Codex hook manifests, the Codex installer entrypoint, omo-native generated modules) depended on separate per-file tests. `script/verify-build-clean-tree.ts` now runs after the build and fails on any tracked change or untracked file. A scratch commit holding the pre-4ddd4b7e25 `bunshin-ts/sdk.js` passed the old schema-only gate and failed the new one. References: https://github.com/hhgyu/oh-my-openagent/pull/76.
