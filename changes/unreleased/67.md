## 2026-11-15 - CI temp leaks and cold test-child transpiles (#67)

The keychain helper build owns clang's scratch temp dir (the 16-entry macOS shard 2 leak). The session-manager storage test keeps its module-mocked storage root in the process-scoped temp dir, because `mock.restore()` does not undo `mock.module()` and later writers recreated it. The test preloads and CI share one Bun runtime transpiler cache between the test process and its children, which removes the 4 s cold compile behind the Windows fresh-process timeouts.
