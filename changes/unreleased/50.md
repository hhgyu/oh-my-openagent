### Added

- OpenCode 2 memory maintenance now runs runtime retention and the size cap with the bound session's `memory.runtime` settings (live sessions and their sidecars are never removed, `omo.retentionAt` is stamped), then one slice of the host sweep over identities the process does not host (global settings only; off under `CI`). Crashed transient runs other hosts left in the shared memory root are reclaimed once per memory root per day, 1 s after the bind.
- OpenCode 2 `/doctor` reports the `runtime-size` line and the `runtimeSize` JSON key, and accepts `--fix [--dry-run]`: the shared stale reflection-lock reaper with its minimal settle (as `omo doctor --fix`) plus the dead-owner lock reclaim.

### Changed

- The runtime retention pass, `memory.runtime` resolution and the transient-run sweep moved from omo-senpi into memory-core (`./transient` subpath); Senpi keeps its module paths as re-export shims with the `omo-senpi memory` log prefix.
