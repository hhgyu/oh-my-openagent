### Added

- OpenCode 2 memory session journal: a bound root session's transcript (user turns, assistant text, reasoning, tool calls with results, assistant errors) is reconciled into the memory-core transcript journal on idle and at first bind, idempotently by source line id.
- OpenCode 2 memory commands `memory`, `memfs`, `remember`, `memory-init` (Native `init`; OpenCode 2 already ships a builtin `init`), `recompile`, `memory-repository` and `search`. Output is shown through an `omo-memory` `command.output` RPC event (dialog or toast in the OmO V2 TUI) and recorded as a session message that is stripped from model requests, so command dumps never reach the model and no turn starts.

### Changed

- The host-neutral memory command handlers moved from the Senpi adapter into `@oh-my-opencode/memory-core/commands` (`command-metadata` for the dependency-free metadata); the Senpi adapter delegates to them unchanged.
