### Added

- OpenCode 2 memory facts: after real user input, a bound root session's settled journal delta is queued and debounced, extracted by a hidden owned `omo-facts` child whose only tool is `record_fact`, and applied by the parent with the original facts batch, lock, secret-screening, failure-backoff and recovery semantics. There is no session shutdown event on OpenCode 2, so the final batch and stranded runs reconcile at the next bind, and a facts child stranded by a host crash is reclaimed through the journal's dead-owner takeover.
- OpenCode 2 memory commands `facts` and `agreements`.

### Changed

- The Kibitzer child port is generalized into a shared memory child port.
- `/facts` handlers (status, failure cause, failure detail, people payload) moved into memory-core; the Senpi adapter delegates unchanged.

### Fixed

- `/facts` no longer counts the claims file as a pending batch, and shows backoff waits under a minute in seconds instead of `now`.
