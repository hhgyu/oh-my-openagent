### Added

- OpenCode 2 task children follow their parent's approval mode. OpenCode copies a parent session's permission rules into a new child but never carries a later change; an owned child now takes every later change of its parent's rules, in order, and a change that could not be written is recorded on the task log and retried on the parent's next change. A child's approval requests and questions already surface on the parent through OpenCode's own session family view.

### Fixed

- A task whose category or agent is pinned to several models, none of which the model registry serves, is refused naming every pinned model in try order instead of only the first.
