### Added

- OpenCode 2 sessions get Native's `create_goal`, `update_goal` and `get_goal` tools: the senpi engine's own goal tools and store, bound to the calling session (each session has its own goal), with Native's completion check against open `todowrite` tasks and per-session usage accounting. An `eval` cell's agent-toolkit SDK reads that goal as its driver through `PI_GOAL_STORE_FILE`. The plugin option `omo-goal-enabled: false` turns it off.
- OpenCode 2 continues an active ulw-execute work plan as Native does: when the session settles with unchecked top-level boxes in a boulder work it owns, one hidden continuation turn names the plan and the next box, and a prompt sent mid-run carries the ulw-execute reminder. The ulw-execute skill is served on OpenCode 2 and records sessions as `opencode:<session_id>`, and the ulw-loop continuation defers to this one while such work exists. The plugin option `omo-ulw-execute-enabled: false` turns it off.
