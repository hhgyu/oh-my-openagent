## 2026-11-12 - Move the memory sync runner into memory-core (#16)

First slice of the OpenCode 2 memory sync port (S8a). `git mv` of `sync-runner`, `device-session/resolver` (now `device-session-resolver`), `sync-config-error`, `sync-session-deferred` and the sync RPC contract/ports/operation/coordinator/registration (with their tests) into `packages/memory-core/src/sync/runner/`, behind the explicit `./sync-runner` export. The logger becomes a local `SyncRunnerLogger` and `loadRuntime` a required option (a default dynamic import inside memory-core could pull Loro into the main Senpi bundle); Senpi passes `() => import("#omo-memory-sync-runtime")`. `sync-rpc-claims` (team-core locks; moving it would create a cycle), the CLI account source (imports the omo-opencode service-auth adapter) and the Senpi sidecar entry stay in omo-senpi and are injected. Senpi bundles rebuilt. References: https://github.com/hhgyu/oh-my-openagent/pull/16.
