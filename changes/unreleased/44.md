## 2026-11-13 - OpenCode 2 live DAG status (#44)

The V2 host projects existing Native workflow snapshots through a read-only RPC and publishes changed views after durable checkpoint commits. The TUI uses the public `session.composer.top` slot and host-managed reactive storage without a polling timer. Isolated OpenCode 2.2.6 server and Windows PTY QA prove a real two-node workflow, running and failed updates, session separation, deduplication, and a mounted panel refreshing from events.
