### Added

- OpenCode 2 thread tools reach sessions in the other OpenCode 2 servers on the same machine that share the agent dir. Each server publishes a private endpoint entry under `<agent dir>/gateway/opencode-v2-endpoints/` and serves a loopback, secret-gated thread RPC; `thread_list`, `thread_read`, `thread_send` and the control tools see and reach the other servers' sessions with the same exactly-once delivery and reply rules. A dead server's entry is ignored and deleted on the next read.

## 2026-11-14 - OpenCode 2 thread tools across servers on one machine (#61)

`v2/threads/registry.ts` (0600 entries: pid, loopback URL, per-start secret; dead-pid cleanup) and `v2/threads/peer.ts` (list, wake, UI answer and a whitelist of session and catalog calls) let the address book, the gateway endpoint port and the control tools span every OpenCode 2 server of the agent dir; delivery state stays in the shared gateway store. Two isolated `opencode serve` processes with a local mock model cover listing, an exactly-once send with a deduplicated retry, the reply back, a cross-server read, and a hard-killed server whose entry is ignored and removed. References: https://github.com/hhgyu/oh-my-openagent/pull/61.
