### Changed

- Memory git diagnostics (`OMO_GIT_TIMEOUT_DIAGNOSTICS_DIR`, off unless set) now also record a git that is still running at half of a budget of 10 s or more: a `git-stall-<pid>-<ts>.json` with the process table and its volume snapshot evidence, taken while the git is still stalled. The git keeps its full budget; nothing waits for the record, and no timeout or retry changes. Previously only a git that ran out its whole budget was recorded, which a caller with a shorter deadline of its own never saw.
