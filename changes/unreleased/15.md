## 2026-11-12 - OpenCode 2 memory reflection (#15)

S7e-S7g of the OpenCode 2 memory port. The child runs on the memory child port (sessions are pinned to the host directory, so the worktree is reached through confined tools, not a cwd). The runner reserves through `ReflectionReservationStore`, creates the worktree, writes the Native transcript payload, launches, then runs `validateCompletion` -> `integrateValidatedReflection` -> `store.complete` with cleanup on every path; recovery reclaims stranded child rows and releases dead in-process launchers (`launch_interrupted`). `reflection_grep` rejects unsafe patterns. Model resolution: category chain, pinned model, then a ladder restricted to consented providers (integration with a connection or declared in config); no model -> `category_unavailable`.
