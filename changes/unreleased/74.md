### Fixed

- An OpenCode 2 task child whose last run had already finished when a plugin reload or a server restart took its observer no longer stays `running` forever with no completion: the restored run settles once with the answer the earlier observer recorded, after the host reports the session idle, and the child gets no restart continuation. A continuation that queues behind a run an in-process reload left running settles once instead of turning uncertain, and a turn held for the child's own background work is confirmed once its last wake source ends, so it cannot stay held forever.

## 2026-11-16 - OpenCode 2 task settlement after a reload or restart (#74)

`host/owned-child-outcome.ts` adds `retainedTurnOutcome` (only observer endings on the binding, no run after the last terminal) and skips a run already in flight before a later turn observer's first start; `orchestration/native-task/owned-handle.ts` settles a revived, finished turn with that outcome after `session.wait`; the shared `senpi-task` held-settlement core gains an opt-in `confirmStatuses` that the V2 observer sets to error and completed (Senpi keeps error only, bundle rebuilt).
