## 2026-11-18 - Telemetry reads prompt-free agent names, so omo.js sheds the builtin agent prompts (#92)

The telemetry schemas (`event-schemas.ts`, `delegation-schema.ts`, `delegation-projection.ts`) need only the four curated agent names, but they imported `CURATED_READONLY_AGENT_NAMES` from the `@oh-my-opencode/senpi-task/agents-builtin` barrel. That pulled all seven builtin agent definitions (about 39 KB, mostly prompt text) into `omo.js`, although `omo-task.js` (`#omo-task-runtime`) already ships them for the task component. The names now come from `agents/builtin/names.ts` through the new `@oh-my-opencode/senpi-task/agent-names` export. `builtin-agents.test.ts` pins that list to the definitions, and a metafile-input test in `build-extension.test.mjs` keeps the definitions out of the entry bundle.
