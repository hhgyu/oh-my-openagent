### Fixed

- Senpi no longer leaves the session-start process sweep running after `session_shutdown`. Shutdown now stops the sweep's process enumeration (PowerShell on Windows, `ps` elsewhere) and waits for that child to exit before it returns.
- A new thread gateway store opens faster. Schema migrations no longer flush to disk once per schema version, which took seconds on a busy Windows disk.

## 2026-11-25 - Stop the process sweep on shutdown and open new gateway stores faster (#116)

`session_shutdown` aborts the in-flight session-start sweep and waits until its process enumeration has exited, so a reload or test cleanup no longer finds a stray PowerShell recreating its temp directory. Gateway store migrations commit at `synchronous = NORMAL` in WAL mode and restore the previous level before any other write. Each step stays atomic, and a crash re-applies the newest steps from `user_version`.
