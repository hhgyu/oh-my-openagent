### Added

- OpenCode 2 revives `task` children left behind by a server restart as soon as the restarted server serves the project again, without waiting for a parent tool call. Each revival still asks the parent session's `subagent` approval (one prompt per child under an "ask" rule); a refused child stays parked and its parent gets one notice.
- OpenCode 2 `task` children that start a run on their own after their turn settled re-open the task, and the parent gets one more completion notice with that run's answer (Native `onSelfResumed`).

### Fixed

- A self-resumed owned child's task record moves its owned-session run reference with the new run, so the record stays readable and the resumed run settles.
