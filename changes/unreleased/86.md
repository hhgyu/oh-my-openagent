### Fixed

- On Windows, archive listing and extraction (the comment-checker download, zip binaries) use the bundled `System32\tar.exe`, so they work when Git for Windows' GNU tar comes first on PATH. Before, that tar read `C:\...` as a remote host, the download failed, and the comment-checker never installed.
- Session-history project discovery compares directories by their exact NTFS file IDs. File IDs above 2^53 used to drop to a case-folded path comparison, so whether two distinct directories merged depended on their IDs.
- Memory component cleanup waits for the transcript journal writes that the final facts drain started, so none land after cleanup has returned. An aborted journal reconcile stops waiting on a stalled host read, which keeps shutdown bounded.
