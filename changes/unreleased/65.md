### Added

- OpenCode 2 `/omo:goal`: Native's `/goal` (show, `pause`, `resume`, `clear`, `<objective>`) on the senpi engine's own handler, bound to the session's goal. Setting or resuming a goal starts the goal loop at once when the session is idle. OpenCode's own `/goal` is untouched.

### Fixed

- OpenCode 2 texts that named a Native command (memory command output, memory tool refusals, memory sync status, the goal footer and goal tool results, computer tool messages, the computer-use skill and eval prelude docs, the staged ulw-loop and ulw-execute skills) now name the `/omo:` command, so `/init` and `/goal` no longer point users at OpenCode's own commands.
