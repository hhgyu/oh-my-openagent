## 2026-11-13 - Host subagent sessions own their OmO task root (#47)

The V2 task service decides ownership from the OmO child journals of the caller's host ancestors. Each journal records every OmO child before its host session exists and never deletes the record. A host subagent with no claim on itself or on any session between it and the top-level session gets its own root lease. The root's host parent is checked during ancestry verification and completion notification delivery. Decision D-032, parity row P-46. References: https://github.com/hhgyu/oh-my-openagent/pull/47.
