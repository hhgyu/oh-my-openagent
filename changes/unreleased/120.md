### Fixed

- The private sign-in file's parent directory check no longer refuses every home on a host that cannot report a POSIX owner (Windows). There, owner and mode are not judged, while symlinks and non-directories are still refused. On Linux the full owner and mode check is unchanged.

## 2026-11-26 - Judge credential parent ownership only where the host can answer it (#120)

The credential parent check added for the Linux sign-in file compared directory owners with a uid of -1 on hosts without `process.getuid`, so any store using the Linux family there refused its home as a foreign owner. The check now skips owner and mode only when no uid exists, and the account CLI's real state-file cases run on POSIX hosts only, matching upstream #14556.
