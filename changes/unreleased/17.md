### Added

- OpenCode 2 `workflow` runs can now run in the background: `start` with `detach=true` and `wait` (detach defaults to true) admit every node that can start now inside the call and return at once. A background run advances only on the model's next `workflow` call; when an admitted node finishes outside a call, the root session gets one wake that names the settled, ready and running nodes and asks for `workflow action=wait`. Settles that land before the model acts share that one wake. `cancel`, `cancel_node`, `retry`, `send`, `amend`, `load_skills` nodes and process execution mode stay refused.

## 2026-11-12 - OpenCode 2 detached workflow and run wake (#17)

S6d of the OpenCode 2 DAG port. A detached drive runs the same per-call scheduler as a blocking one and returns once admission is quiet (no node start in flight, no settled child left unfolded, unchanged checkpoint); admission is then held as before, so no node starts without a live call. `v2/orchestration/native-dag/wake.ts` is a component-owned wake owner over the joined `session.get` and the gated `session.synthetic` route (`resume: true`): it watches every run a call stopped driving, reads child status from the persisted task records without call authority, and posts one wake per (run, checkpoint seq) with the deterministic id `msg_omo_dag_` + 40 hex of sha256(`dag:<runId>:<seq>`), or `dag:<runId>:terminal` when nothing can run any more. `v2/host/dag-delivery-journal.ts` journals intent before transport and the ACK after; every delivery re-checks the plugin generation, that no call drives the run, that the run exists, is owned by the root and is not terminal, that its checkpoint is unchanged, that the wake is not ACKed and that the root session exists in this directory. Journal rows are retired once the run is gone, and the owner stops on dispose. References: https://github.com/hhgyu/oh-my-openagent/pull/17.
