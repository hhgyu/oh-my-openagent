## 2026-11-26 - Record Volume Shadow Copy evidence with a Windows git timeout (#122)

A Windows CI `git add` that waited past its 30 s timeout was attributed to a Volume Shadow Copy snapshot only by process start times. The opt-in git timeout record now carries a `volumeShadowCopy` field on Windows: VSS, VSSVC, volsnap and VolumeSnapshot-Driver events from the Application and System logs for the last 10 minutes, the `VSSVC.exe` process with its creation time, and `vssadmin list shadows` when VSSVC is already running. The diagnostic never starts the service. Git's timeout, its kill path and the process snapshot are unchanged, and the extra collection is bounded at 10 s and runs only on an actual timeout.
