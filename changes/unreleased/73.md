### Added

- OpenCode 2 OmO task panel: the Native task job widget ported to the V2 host. The `omo.task` RPC (`status` plus `rpc.omo.task.updated`) lists a session's task records (its own spawns plus, for a root, its whole tree) from the task journal, and a `session.composer.top` panel shows the live and parked background tasks with label, route, status and elapsed time. A task whose child idles between turns while waiting on its own background work stays `running` until its record is terminal; a finished task stays 60 s with its terminal state and result head; a restarted server lists revived tasks again. The plugin option `omo-task-panel-enabled: false` turns the RPC and the panel off.

### Changed

- The task widget model (scope, label, live selection, parked state, elapsed time, read-only row projection) is shared as `@oh-my-opencode/senpi-task/task-widget`; the Senpi task status rows import it.

## 2026-11-15 - OpenCode 2 OmO task panel (#73)

`senpi-task/src/task-widget.ts` holds the harness-neutral model; `omo-senpi` `status-row-format.ts` imports it. On V2, `native-task/task-status-rpc.ts` projects records from the root's state directory (validated against the root session hash, never walked when the project is `$HOME`), the owned runtime reports every store write through `createMutationNotifyingStore`, and `tui/task-panel.ts` renders the panel from the RPC. Parity row P-65, decision D-040. Actual isolated OpenCode 2.2.6 runs with a local mock model show a task running through a 40 s background wait, then completed with its result, a cancelled task, and a running task listed again after a hard server restart.
