### Added

- OpenCode 2 sessions can run the `ulw-loop` skill as on Senpi. The skill loads through OpenCode's own `skill` tool. An `eval` JS cell imports the agent-toolkit SDK with `` const { agentToolkit } = await import(`${env("OMO_AGENT_TOOLKIT_SDK_ROOT")}/sdk.js`) ``, bound to the calling session by the host (a cell cannot rebind it). An active incomplete loop gets one continuation turn when the session settles. A prompt sent mid-run carries the loop reminder, and the prompt footer shows the `ultraworking` spinner while the loop is active. The plugin option `omo-ulw-loop-enabled: false` turns it off. Not ported yet (parity row P-49): the model-callable `create_goal` / `get_goal` / `update_goal` tools the skill names, run-completion reporting, and the `mass-ulw` / `ultrawork` skills the skill points to.

## 2026-11-14 - OpenCode 2 ulw-loop port (#54)

The Senpi session SDK glue (`session-binding`, `session-toolkit`, driver goal and relation, session-file header) moves next to the loop engine in `packages/omo-codex/plugin/components/ulw-loop/src/session-sdk/`, with the Senpi component's status classification, continuation policy and footer frames (`loop-continuation.ts`) and a host status read (`host-status.ts`); `@oh-my-opencode/omo-codex` exports it as `./ulw-loop-session-sdk/*`.
