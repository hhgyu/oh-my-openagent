## 2026-11-15 - OpenCode 2 owned-child persist stops lock churn (#68)

`owned-events.ts` `persist()` checks the in-memory projection set against the own-log signature (ino:size:mtime) before `withTaskRecordLock`; an unknown frame or a moved signature still takes the locked reconcile path. Measured on real modules: 178 lock fs events/s to 0 under a 20ms pump. Real OpenCode 2.2.6 QA with live owned children: lock events stop once the children go quiet and plugin reloads stop with them.
