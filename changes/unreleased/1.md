### Fixed

### Added

- OpenCode 2 runs the Native task engine from the default plugin entry: public `task`, `task_output`, `task_send` and `task_cancel` delegate to owned child sessions through the original Native manager, with the owned-child tool guard bound on every child (disable with the `omo-native-task-enabled: false` plugin option).
- Owned children are durably parked on plugin unload or reload (their own session gets a trailing deny rule and a marker) and are restored on the parent's next `task_send` under a fresh authorization, with original permissions and metadata put back; observed conflicting edits are refused instead of overwritten.
- OpenCode 2 ports of the Native `ultrawork`, `comment-checker`, `todo-fanout-reminder` and `question-gates` components.
- OpenCode 2 memory: root-session memory binding, pinned memory block projection, the `memory` and `memory_apply_patch` tools with session/turn commit trailers, and Kibitzer recall judged by a resident read-only child that nudges once through the context hook.

### Changed

- The OpenCode builds stage the memory-core runtime personas next to `dist/` and `dist/v2`, so a missing persona can no longer disable the plugin.
