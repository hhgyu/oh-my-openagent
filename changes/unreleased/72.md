### Fixed

- `omo-git-job-helper` testkit: the restricted Medium token `testkit_run_as_standard` runs the helper under now carries a standard user default DACL (user and SYSTEM full access) instead of the elevated runner's (Administrators, SYSTEM). With Administrators deny-only the helper's members died at load with `0xC0000142` when the tests ran below a non-MSYS shell, failing N8 in the `Desktop engine` Windows legs.
- `senpi-desktop-session`: the Linux runtime-directory resolver checks `XDG_RUNTIME_DIR` for a leading `/` (the POSIX absolute-path rule) instead of the host's `Path::is_absolute`, so its unit tests give the Linux answer on every host. Linux behavior is unchanged.
