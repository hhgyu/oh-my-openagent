### Changed

- On OpenCode 2, the eighteen `thread_*` tools can be called from OpenCode's Code Mode (`execute`, e.g. `tools.thread_list({})`) as well as from the omo `eval` kernel. Before, Code Mode answered `Unknown tool 'thread_list'`. The tools still stay out of the direct tool list; if another plugin already registered one of the names, they are left out of Code Mode and eval keeps them.

## 2026-11-19 - V2 thread tools in Code Mode (#97)

`packages/omo-opencode/src/v2/threads/codemode.ts` registers each owned thread host tool as a `codemode: true` OpenCode tool that runs the same body with the call's SDK context, so gateway rows, receipts, the `thread_send` permission (verdict rethrown unchanged) and the reply allowance are shared with eval. `v2/index.ts` registers them after the thread component starts.
