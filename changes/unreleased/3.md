## 2026-11-11 - OpenCode 2 skill permission for task load_skills (#3)

`authorizeSkills` resolves names against a call-time `skill.list`, asserts `skill` per distinct id with the joined permission owner and the parent tool-call source, re-checks the name-to-id mapping after each assert and returns a per-call loader. Actual isolated OpenCode 2.2.6 runs with a local mock model cover directory and builtin skills, allow, deny on the id, a display-name rule that does not decide, and a two-skill request with one denial.
