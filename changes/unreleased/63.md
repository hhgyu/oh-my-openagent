### Added

- An active Native goal now keeps an OpenCode 2 session working as on Native: when the session settles, one hidden continuation turn asks the agent to continue toward the goal, under the senpi engine's own guards (stale progress stops it, 8 continuations in a row or 60 without progress block it, repeated output and truncation are caught). After a turn the user started it waits the engine's 10 second grace first, it waits while the session's own background work runs, the user's next message resets it, and interrupting the run blocks the goal. Goal, ulw-execute and ulw-loop continuations now answer each settle in Native's order (goal first), at most one per settle.
- The OpenCode 2 footer shows the Native goal status ("Pursuing goal (5m)", "Goal blocked: ...", "... Goal achieved") beside the ulw-loop indicator.

### Changed

- On OpenCode 2, a ulw-execute work left `active` by a session that no longer exists is paused after the stale threshold, as Native does: the sessions API stands in for Native's transcript check, and a session that is executing or was updated recently keeps its work. The ulw-execute continuation names the OpenCode `task` tool instead of Senpi's.
